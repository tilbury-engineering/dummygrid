# DummyGrid API

Secure backend for:
- child-safe karting-only AI web search
- driver accounts/profile persistence
- private video uploads via S3-compatible storage
- frame-based AI karting coaching

Required environment:
- OPENAI_API_KEY
- DATABASE_URL
- SITE_ORIGIN=https://tilbury-engineering.github.io
- S3_ENDPOINT
- S3_BUCKET
- S3_ACCESS_KEY_ID
- S3_SECRET_ACCESS_KEY
- S3_REGION=auto

Optional:
- OPENAI_MODEL=gpt-5.6-sol
